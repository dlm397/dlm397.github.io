Career Ladder Identifier and Financial Forecaster

The CLIFF tools are designed to help lower-income households think more clearly about career pathways, financial decision-making, and the tradeoffs associated with different trajectories over time. The project is used by career counselors and financial coaches to help clients make more informed decisions about their future.

Project Focus

  • Household financial forecasting
  • Career pathway evaluation
  • Decision support for lower-income households

Project Summary

CLIFF is a practical set of tools meant to make complex economic tradeoffs more transparent. Rather than focusing solely on static outcomes, the project emphasizes how household decisions and earnings trajectories evolve over time and how those dynamics affect financial stability and long-term opportunity.

My Work on the Project
